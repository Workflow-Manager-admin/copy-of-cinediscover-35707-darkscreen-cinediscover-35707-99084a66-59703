Clapperboard Favicon
====================

This `favicon.png` is a simple clapperboard placeholder created for your CineDiscover app.
You may replace this file with any custom 32x32 or 48x48 PNG or ICO file for a personalized favicon.

To replace:
1. Create or obtain a clapperboard (movie-themed) icon file named `favicon.png` (or `favicon.ico`).
2. Replace this file in the `public` directory.
3. Ensure the file is referenced in your `index.html` as:
   <link rel="icon" type="image/png" href="%PUBLIC_URL%/favicon.png" />

For the best appearance, use a square (preferably 32x32px or 48x48px) icon with a transparent background.
